# 24dle Feedback & Issue Tracker

Official public issue and feedback tracker for [24dle](https://24dle.com.ar) — the daily arithmetic card game.

---

## 💬 How to Contribute & Report

If you encountered a bug, have an idea for a new feature, or want to share feedback:

1. **[Search existing issues](https://github.com/manudelp/24dle-feedback/issues)** to see if your topic has already been reported.
2. If not, **[Open a new issue](https://github.com/manudelp/24dle-feedback/issues/new/choose)** using one of our templates:
   - **Bug Report:** Let us know what went wrong, including device/browser information and card combinations if relevant.
   - **Feature Request:** Suggest ideas for game modes, controls, UI, or improvements.
   - **Privacy / Account Requests:** Inquire about account data or deletion requests.
